# HR Employee Report Dashboard (Power BI)
An interactive Power BI dashboard analyzing workforce data for 689 employees across 5 countries (Egypt, Lebanon, Saudi Arabia, Syria, UAE).
## Key Metrics
- Total employees: 689
- Total monthly salary: 1.4M
- Average job rate: 3.59
## What the dashboard shows
- Employees by center (Main, North, West, South, East)
- Employees by department (Manufacturing is the largest with 140)
- Employee distribution by country on an interactive map
- Gender split: 65% male, 35% female
- Hiring trend by year (2016-2020), peaking at 248 in 2019
## Interactivity
- Country buttons and a Center dropdown to filter all visuals
